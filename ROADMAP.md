# GPOS v2.0+ Roadmap: The Path to Enterprise

Now that **v2.0.0** is live with a solid Multi-Branch architecture, we have a world-class foundation. Here is the proposed technical roadmap for the next phases of development.

## 📍 Phase 2: Inter-Branch & Logistics
*   **Stock Transfers**: Implement a workflow to move inventory between branches (e.g., "Branch A" sends 50 units to "Branch B") with "Outgoing" and "Incoming" status tracking.
*   **Centralized Purchasing**: Allow the Business Owner to create one large Purchase Order and distribute items to specific branches upon arrival.
*   **Branch-Specific Pricing**: Refine the logic to allow different retail prices for the same product in different cities/locations.

## 📊 Phase 3: Intelligence & Auditing
*   **Consolidated Dashboard**: A "God View" for owners to see total revenue, top-selling products, and stock value across ALL branches in one chart.
*   **Employee Activity Logs**: Track every "Void", "Return", and "Discount" with a timestamp and user ID for loss prevention and accountability.
*   **Advanced Export**: Export full financial year reports in Excel/PDF format, categorized by branch.

## 📱 Phase 4: Customer & Marketing
*   **Unified Loyalty**: Option to allow customers to use their points at ANY branch of the same business.
*   **SMS/WhatsApp Campaigns**: Bulk notify customers about new stock or sales (specifically filtered by the branch they usually visit).
*   **Customer Credit (Khata)**: A formal "Customer Balance" system to track credits and partial payments.

## 🛠️ Phase 5: Reliability & Scale
*   **Conflict Resolution**: Enhanced offline sync logic for cases where two cashiers edit the same product stock simultaneously while offline.
*   **Automated Billing**: Integrate a subscription system (Stripe/EasyPaisa) to manage user licenses automatically.
*   **API Layer**: Prepare a REST API for third-party integrations (e.g., connecting a Shopify store to GPOS inventory).
